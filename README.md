# 出行时间地图

根据小红书展示的自驾等时圈与铁路直达范围交互制作的独立演示版。页面是纯静态文件，入口为 `dist/index.html`，可直接用静态网站服务托管。

## 功能

- 搜索内置样本城市、输入 `纬度, 经度` 或点击地图选择出发点。
- 切换自驾估算与铁路时间示意，调整 4–18 小时时限，平移、缩放地图。
- 浏览样本城市时间统计，导出 CSV 和 PNG。
- 铁路页可导入本机 CSV：`出发城市,到达城市,分钟`，显示文件中的直达记录；同一城市对有多条记录时采用最短时间。CSV 只在当前浏览器页面内读取，不上传。

## 数据与限制

自驾时间使用球面距离和平均速度的简化模型，**不是**高德导航路径规划结果。默认铁路时间同样按距离估算，**不是**12306 实时车次，也不代表实际直达。导入的铁路 CSV 只反映文件自身内容。城市列表是有限样本，不覆盖全国区县；等时圈是连续色带，不是原作品的区县级着色。实际出行前应核对导航和铁路官方信息。

底图瓦片来自 OpenStreetMap，页面中保留署名；底图需要网络连接。PNG 导出在底图无法跨域绘制时会保留时间图层，省略底图。地图边界与行政信息以底图提供者为准。

## 本地运行

```bash
python3 -m http.server 8000 --directory dist
```

打开 `http://localhost:8000/`。无需构建或安装依赖。

## 后续接入真实数据

需要服务端路径规划接口、可核验的铁路时刻数据及相应调用权限。不要把服务端密钥直接写入静态页面。接入后还需要把模型估算状态与真实结果清晰分开，并处理配额、缓存、失败重试及数据更新时间。
